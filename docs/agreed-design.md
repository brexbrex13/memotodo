# MemoTodo v3 合意仕様（2026-10-01）

最新の会話で合意した付箋ボードを基準とする。最初の40項目の提案を一括採用したものではない。

- タイトルを入力してEnterで即登録、Alt+Enterで改行。IME変換確定は登録しない。
- 期限なしの付箋を通常の主役にし、カテゴリの箱と手動順を保持する。重要フラグを付けられる。
- 通常・定期の付箋を同じ一覧で扱う。期限超過、今日、期限近接は上部の帯から横断確認できる。帯は同じタスクへの入口であり、コピーや通知ではない。
- 完了した付箋はボードから外す。完了履歴から再開できる。削除はごみ箱へ。
- 全付箋にリッチメモ（太字・任意色・画像・見出し・箇条書き・チェックリスト・リンク）を付ける。独立メモの種類は設けない。
- 編集は保存状態を示して自動保存、終了・画面移動時も編集内容を保持する。
- 定期設定と各周期の付箋を分離する。前回分未完了でも次周期を追加。周期の完了/見送り/再開は他周期に影響しない。
- 定期設定は初回期限、周期、期限時刻、追加する何日前、近いと判断する何日前、期限前の通知を個別に持つ。日付期限は当日終了、前日指定時刻通知と時間前通知を区別する。
- 定期設定編集は今後生成する付箋に反映、既存の残件・履歴は保持する。一時停止中は生成しない。再開は停止中の周期を補充せず、今後の分から続ける。
- 独自通知ウィンドウを主通知とし、メイン非表示でも表示。最前面・タスクバー非表示・表示時フォーカス非奪取・確認まで保持。複数通知を1窓に集約。
- 確認は完了と別。詳細表示だけで確認扱いにしない。確認/スヌーズ/完了/詳細を提供。未確認とスヌーズは永続化し、起動・復帰で拾う。
- 標準通知は任意の補助。通知音と内容非表示、終了時刻付き保留を設定可能。定期まとめは平日13/17時を初期値、空なら出さない。
- exe横のdataに新規board.dbを保存。旧todo.dbには触らない。旧形式取込は今回対象外。
- Windows常駐、×でトレイ格納、最小化はタスクバー、明示終了で終了。多重起動を防ぐ。
- 検索・状態/カテゴリ/重要/期限フィルタ、手動/期限/新着順、完了履歴、ごみ箱、画像込みバックアップを提供。

## 検証境界
Windowsネイティブ通知のフォーカス、最前面、タスクバー、DPIはWindowsでのみ検証できる。Linuxサーバーモードは業務ロジックと画面検証用であり、これらの代替証拠ではない。
